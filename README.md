# Task Management System

A console-based task management application developed using Java.

## Features
- Add new tasks
- View all tasks
- Search tasks
- Update task details
- Delete tasks
- Mark tasks as completed
- View tasks by priority

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- LinkedList
- HashMap
- PriorityQueue

## How to Run

Compile the program:

    javac TaskManagementSystem.java

Run the program:

    java TaskManagementSystem
